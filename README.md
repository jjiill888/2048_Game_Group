# 2048 Game Emulation (C++)

This group project implements the movement logic of the classic game **2048** in C++. The goal is to complete the `move_left`, `move_right`, `move_up`, and `move_down` functions so that tiles slide and merge correctly on a 5×5 board according to game rules. The program uses `print_board` to display the board, adds a new tile after each valid move, and detects when no further moves are possible. The project will be collaboratively developed and managed via GitHub.
